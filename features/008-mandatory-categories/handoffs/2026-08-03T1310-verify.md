# verify — handoff summary

**On authorship.** The verdicts and evidence below are reviewer-3's, from a
review agent run with fresh context; `main` transcribed them into this file
because the reviewer agents returned reports rather than writing handoffs. The
transcription is clerical — no judgment here is the implementer's, except where
the last criterion says so explicitly.

## What was verified

Three rounds against the branch, each by an agent that had not seen the
implementation being written. Every criterion was exercised through a door a
client can reach rather than through the service layer a step handler calls.

## Round by round

**Round 1 — NO.** Nine defects, two blocking. D1 and D2 are described in the
refine handoff; the rest were documentation and surface defects (D3, the
recurring edit dialog offering an affordance its endpoint cannot honour, so
typing a name failed 100% of the time; D5..D9).

**Round 2 — YES, with six findings.** The sharpest was N4, on a test the
implementer had written specifically to make a false claim true:
`test_model_schema_drift.py` normalised with `[\s()]+`, stripping the
parentheses that carry the precedence. `(A AND B) OR (C AND D)` and
`A AND (B OR C) AND D` hold the same tokens and mean opposite things — under
the second, no expense could ever be stored — and the test compared them equal.
N1/N2 were escalated: global name uniqueness produced a state with no way out.

**Round 3 — YES, one blocker (N7).** It lands on `🛡️ Auto Insurance`, the exact
production pair acs.md and ADR-0042 both cite as the reason the feature exists.
Production carries it twice, one archived and one active, from before the rule.
`_by_name` returned the first row in query order, and in that pair the archived
row has the lower id — so creating a third was refused with *"an archived
expense category is already named 'Auto Insurance' — restore it instead"*,
which is wrong: an active one already exists. Following that advice called
`unarchive_category`, which had no duplicate guard, and produced two active
same-name categories of the same direction. **The feature's own advice talked
the owner into the duplicate the feature exists to eliminate.**

## What is still open

One criterion, and it is procedural. N7's fix is not independently verified —
see the exit criteria. Nothing else in the seventeen findings remains.

Four findings were filed rather than fixed because they pre-date this feature:
C12, C13, C14, C15.
