## The defect (not a refactor)

| Creation path | Sets direction? | 0006 backfill |
|---|---|---|
| `transactions.transfer()` | was ✅ | correct |
| `goals.contribute_to_goal()` | was ❌ → now ✅ | correct |
| `planned._confirm_transfer()` | was ❌ → now ✅ | **inverted** |

Two failure modes, both closed in code: post-0006 transfers from the two
missing paths were undeletable (`delete_transaction` is fail-loud on a
directionless leg), and historical planned-confirm pairs carry a reversed
direction that would have moved balances the wrong way on deletion.

Pinned by: `test_confirm_planned_transfer_stores_both_leg_directions`,
`test_confirmed_planned_transfer_deletes_as_a_pair` (asserts both balances
return to their pre-transfer values), `test_goal_contribution_stores_both_leg_directions`,
and five migration tests including `test_0006_inverts_a_planned_confirm_pair`
which pins the bug 0007 exists to correct.
