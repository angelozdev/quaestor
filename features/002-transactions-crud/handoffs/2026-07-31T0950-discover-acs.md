# discover-acs — handoff summary

## What I did

Discovered feature 002's acceptance criteria in reverse-engineer mode:
extracted candidates from the shipped code, its 58 unit tests, the P0 core
design, ADR-0021 and ADR-0027; interviewed only the four genuine gaps the
material left undecided (each explained with concrete examples per Angelo's

drift (permanent delete wording, `date DESC` order, target behaviors).

## Gap decisions (user-confirmed 2026-07-31)

1. **Tags:** full surface parity — add/remove on create and edit from UI,
   API and agent (today: agent-only, creation-only, no removal). AC-6.
2. **Delete:** permanent with balance reversal stays; no trash. AC-4.
3. **Transfers:** deletable as an atomic pair, both balances reversed —
   requires storing each leg's direction (schema change + data migration;
   `backend/src/quaestor/migrations/**` is capped at low autonomy; ADR due
   at plan time per CLAUDE.md). AC-5.
4. **Transfer sides:** independently editable (real bank dates differ) but
   the pair must always be visible/reachable in the interface. AC-10.

## Findings

- Tag assignment today is reachable ONLY through the agent at creation
  (`tag_transaction` has no other caller); the tags router manages tag
  masters only. The UI uses tags solely as a list filter.
- ADR-0021's title still says "created_at desc" while its decision (and the
  code) is `date DESC, id DESC` — cosmetic ADR drift, candidate for the
  doc-drift-cleanup roadmap item, not fixed here.
- Domain coverage checklists (3b): no match — auth-oauth / web-seo /
  deploy-model don't apply; accessibility and data-migration checklists
  don't exist in the plugin yet (data-migration would have applied to AC-5).
- Overlap: cross-currency transfer mechanics and read-time COP conversion
  are pinned by feature 005's suite; AC-2/AC-9 reference them without
  duplicating — a consistency-check target after CP3.
- ATDD red phase expected on AC-5 (transfer pair deletion) and AC-6 (full
  tagging): both are new target behaviors, deliberately beyond current code.
