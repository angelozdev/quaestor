## Artifacts produced

## Findings

- **A decision in this feature invalidated a scenario in another.** AC-6 makes
  a repeating income that waits for approval impossible to declare — which is
  the point — and feature 006 had an approved scenario whose `Given` built
  exactly that. I stopped rather than edit another feature's `spec.md`, and
  rewrote it only after explicit permission, reusing that spec's existing
  vocabulary and preserving the angle it uniquely covered (an *overdue* income
  staying out of the queue).

- **The textbook mechanism for AC-24 was unusable here.** Per-item SAVEPOINT
  isolation is what SQLAlchemy documents for this shape, and it is
  non-functional under the default pysqlite driver the entire test suite runs
  on — it would have been real in Postgres and fake in the tests meant to prove
  it. Per-charge commit behaves identically on both engines (ADR-0036).

- **Two of three schema questions dissolved.** W3 ("ended" vs "switched off")
  is derived from the end date; W4 (what records a pause) is written as skipped
  occurrences the user can see. Neither needed a column. Final data footprint:
  two enum values, no new tables, no new columns.

- **Mutation testing found a real coverage hole.** The daily cadence —
  the one AC-9's catch-up uses — had no unit test at all in the pure module.
  Score after closing it: 50/51 killed (98%), the single survivor being an
  equivalent mutant on a guard AC-20 makes unreachable, reported as equivalent
  rather than papered over.

- **Two self-inflicted mistakes, both corrected.** A repo-wide `biome --write`
  reformatted 26 files outside my change (reverted); and a regex meant to add
  one argument to 37 test call sites produced invalid syntax in four files
  (repaired, then redone properly via AST — a dry run of which found one
  deliberate call site the textual substitution would have silently broken).
